市町村類型マップ

総務省「類似団体別市町村財政指数表」（令和6年度）の類型区分を、市区町村ごとに表示します。人口と産業構造は令和2年国勢調査、団体は令和7年3月31日現在のものです。

この地図の使い方

類型は、総務省が市町村の財政を条件の似た団体どうしで比べるために、人口と産業構造で市町村を分けた区分です。

  • 自治体名で検索して類型を確かめ、その類型のマスを押すと、同じ類型の団体が一覧で出ます。総務省の指数表や財政状況資料集で類似団体と比べるときに、同じ類型にどの団体が入っていて、どこにあるのかを地図で確認できます。
  • 都道府県や圏域の中で、どの規模と産業構造の団体が多いかが色の濃淡で分かります。「産業構造で塗る」に切り替えると、第1次産業の割合が高い団体は薄い色で表示されるので、こうした団体が多い地域が分かります。
  • 研究や資料には、下部の類型一覧CSVを使えます。CSVには団体コード（6桁）が付いているので、統計表や調査データと市区町村単位で結合し、人口規模と産業構造を表す区分として集計や層別に使えます。

類型は人口と産業構造の2つだけで決まり、自然条件や社会・経済条件は反映されていません。また、指数表は各類型の実態を示したもので、あるべき姿を示したものではありません（作成要領「指数表の利用の方法」）。
