市町村類型マップ

総務省「類似団体別市町村財政指数表」令和6年度の類型区分（人口・産業構造は令和2年国勢調査、団体は令和7年3月31日現在）

この地図の使い方

類型は、総務省が市町村の財政を「似た条件の団体」と比べるために、人口と産業構造で市町村を分けたものです。

  • 比べる相手を決める：自治体名で検索して類型を確かめ、その類型のマスを押すと同じ類型の団体が一覧で出ます。総務省の指数表や財政状況資料集で類似団体と比べるとき、相手の顔ぶれと所在地を地図で確認できます。
  • 地域の構成を見る：都道府県や圏域の中で、どの規模・産業構造の団体が多いかを色の濃淡で見られます。「産業構造で塗る」に切り替えると、第1次産業の割合が高い地域（色の薄い団体）がまとまって見えます。
  • 研究や資料に使う：下部の類型一覧CSVには団体コード（6桁）が付いています。統計表や調査データと市区町村単位で結合し、人口規模と産業構造をまとめた区分として集計や層別に使えます。

類型は人口と産業構造の2つだけで決まり、自然条件や社会・経済条件は反映されていません。また、指数表は各類型の実態を示したもので、あるべき姿を示したものではありません（作成要領「指数表の利用の方法」）。

    出典：総務省「類似団体別市町村財政指数表（令和6年度）」、国土数値情報（行政区域データ、2025年1月1日時点）（国土交通省）を加工して作成。
